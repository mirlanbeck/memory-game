# Memory Game

Игра на поиск пар. Игрок открывает карточки и запоминает их расположение, чтобы найти все 8 пар за наименьшее число ходов.

Проект выполнен в рамках задания RS School. Использованы только HTML, CSS и JavaScript (ES-модули), без фреймворков, библиотек и сборщика.

## Возможности

- Поле из 16 карточек (8 пар эмодзи), перемешиваются при загрузке страницы и при каждой новой игре.
- Один ход — открытие двух разных карточек. Совпавшая пара остаётся открытой, несовпавшая закрывается через 1 секунду; пока она открыта, другие карточки выбрать нельзя.
- Счётчики ходов и найденных пар (`N из 8`).
- Кнопка «Новая игра» работает в любой момент: отменяет таймер закрытия, перемешивает карточки и обнуляет счётчики.
- Модальное окно победы с итоговым числом ходов открывается автоматически.
- Таблица лидеров (топ-10) хранится в `localStorage`: место, число ходов и дата в формате ДД.ММ.ГГГГ. При равенстве ходов выше более ранняя игра.
- Модальные окна закрываются кнопкой «Закрыть», кликом по затемнённому фону или клавишей Escape. Пока окно открыто, прокрутка страницы заблокирована, а карточки и кнопки хедера недоступны.
- Вся разметка создаётся из JavaScript через `document.createElement`, в `<body>` только тег `<script>`.

## Запуск локально

Требуется любой современный браузер. Приложение использует ES-модули, поэтому файл `index.html` нужно открывать через локальный веб-сервер, а не двойным кликом (`file://`).

```bash
git clone <ссылка-на-репозиторий>
cd memory-game
git checkout memory-game
```

Затем запустите любой статический сервер, например:

```bash
npx serve .
```

или откройте папку в VS Code и запустите расширение Live Server. После этого откройте в браузере адрес, который выведет сервер (для `serve` это `http://localhost:3000`).

## Как устроено

- Состояние игры хранится в памяти (`game/game.js`) и не сохраняется между перезагрузками: игра всегда начинается заново.
- Интерфейс только отображает состояние: клик по карточке вызывает функцию игры, после чего поле и счётчики перерисовываются из актуального состояния.
- Содержимое закрытой карточки не попадает в DOM, поэтому его нельзя подсмотреть в разметке.
- В `localStorage` (ключ `memory-game:leaderboard`) сохраняются только завершённые игры, по одной записи за победу.

## Изображения

Карточки используют стандартные Unicode-эмодзи, внешние файлы и лицензии не требуются. Внешний вид эмодзи зависит от операционной системы и браузера.
